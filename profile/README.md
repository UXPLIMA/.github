# UXPLIMA

Minecraft server software: Paper plugins, the uxmLib library they are built on, and ready-made server setups. Documentation is at [docs.uxplima.com](https://docs.uxplima.com).

## Plugins

- [uxm-essentials](https://github.com/UXPLIMA/uxm-essentials): the all-in-one essentials suite for Paper, from homes, warps and economy to moderation, NPCs and holograms.
- [uxm-auth](https://github.com/UXPLIMA/uxm-auth): login and registration for offline-mode servers and networks on Paper, Folia and Velocity.
- [uxm-skyblock](https://github.com/UXPLIMA/uxm-skyblock): a config-first Skyblock plugin with island teams, upgrades, generators, bank and warps.

## Libraries

- [uxm-lib](https://github.com/UXPLIMA/uxm-lib): the toolkit every UXPLIMA plugin is built on: GUIs, items, commands, config, storage, HUDs and holograms.
- [uxm-config-updater](https://github.com/UXPLIMA/uxm-config-updater): config updates for plugin users without hassle.

## Tools

- [craftwire](https://github.com/UXPLIMA/craftwire): lets AI agents see and drive Minecraft through MCP: screenshots, camera, GUIs, chat, input and bots.
