### Plugins

**[uxm-essentials](https://github.com/UXPLIMA/uxm-essentials)**<br>
The all-in-one essentials suite for Paper, from homes, warps and economy to moderation, NPCs and holograms.

**[uxm-auth](https://github.com/UXPLIMA/uxm-auth)**<br>
Login and registration for offline-mode servers and networks, on Paper, Folia and Velocity.

### Libraries

**[uxm-lib](https://github.com/UXPLIMA/uxm-lib)**<br>
The toolkit every UXPLIMA plugin is built on: GUIs, items, commands, config, storage, HUDs and holograms.

**[uxm-config-updater](https://github.com/UXPLIMA/uxm-config-updater)**<br>
Config updates for your plugin's users, without hassle.

### Tools

**[craftwire](https://github.com/UXPLIMA/craftwire)**<br>
Lets AI agents see and drive Minecraft through MCP: screenshots, camera, GUIs, chat, input and bots.
